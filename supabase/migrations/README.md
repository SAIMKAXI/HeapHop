The database schema for HeapHop accounts, as applied to the Supabase project. Applying these
in order to a fresh project rebuilds it. They hold no secrets: keys and passwords never live here.

`20261122085155_universities_seed.sql` is generated by `scripts/universities/build.ts` from
`scripts/universities/hec-names.txt` and `short-forms.ts`; edit those and run the script again.
